# Changelog

## 0.4.0

- DSH 与 MCP 共用七个 agent 工具。旧 MCP 工具调用需按实现契约的映射迁移；升级后刷新工具目录，并重新打开项目以取得新的会话 context。
- 新增项目历史知识搜索与来源回读。任务查询默认返回摘要，可按章节读取详情并核对来源。
- 外置文档预览显示符合条件的相对路径图片。源码文档按实现契约、模块、工程治理和运维入口重新组织。
- 项目数据仍使用 schema v3。升级前备份，并按恢复手册保留可匹配的旧构建与数据。

## 0.3.1

- 禁止新增同一计划阶段内的直接或间接依赖，保留存量关系。DSH 简报和 MCP 开工上下文显示当前阶段的工作与审查提示。
- 普通任务可由任意授权 agent（包括提交者）显式验收，无需报告。审计门仍要求独立 agent 带报告，人类仍可验收所有任务。
- 普通 agent 验收记录在界面和简报标为「AI验收（自述）」。存储仍使用 schema v3。回退前须核对旧构建对新增验收记录的兼容性。

## 0.3.0

- 新增可切换的推进视图，用于查看并行任务、验收队列和依赖线路。
- 可选 MCP 新增开工上下文查询以及验收和驳回操作。
