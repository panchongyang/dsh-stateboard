# 约三分钟脱敏文字演示

可直接照读的逐步脚本与实际 agent 参数在 [README 演示](<../README.md#约三分钟文字演示>)。前提是[安装与首次运行](<INSTALL.md>)已完成，并选择自己的脱敏工作区；时长是讲解预算而非实测保证。

演示顺序：建空项目 → 发布计划/任务 → claim/begin → 编辑器创建文件 → 外置登记并关联任务 → 外部编辑 → inspect 查看内容现状 → confirm 字节基线 → 记录普通结果材料 → submit 进入 review → 人工阅读材料 verify/reject。

没有 Git 时可完成全程；Git 仅可选展示只读版本引用，首次 pin 失败显式 current-only。文件编辑、确认基线和文档管理状态互不自动同步，未漂移不代表结论正确。本演示走人工验收，项目板不执行材料里的命令。不要使用真实 store、真实任务 ID 或凭据来录制示例。

演示结束后保留材料，无需删除数据。恢复边界见 [RECOVERY](<RECOVERY.md>)，迁移见 [MIGRATION](<MIGRATION.md>)，精确语义见 [外置文档](<EXTERNAL-DOCS.md>)与[固定引用](<DOC-EXTERNAL-EVIDENCE.md>)。
