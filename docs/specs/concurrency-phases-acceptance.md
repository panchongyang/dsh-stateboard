## 2. 各任务交付边界

- D1：冻结目标字段、CAS 粒度、当前归属/历史版本、任务定义冻结、执行/集成完成语义、API/事件/凭证兼容和回退策略；由人确认争议，不把本次规划授权当实施授权。
- C1：所有计划/任务入口采用一致保护；计划无关变动不使 worker 失效；完整项目 DAG 验环，跨计划转移可原子拒绝；归档覆盖 orphan、租约和 open intent。
- W1：显式 projectId/repo/worktree/session 绑定及权限校验；兼容原工作区映射，不自动新建另一块板。
- W2：专属分支/目录分配、身份核对、幂等登记、失败保留和显式安全回收；不自动丢弃脏成果。
- E1：真实命令 cwd、证据根目录、定义/commit 口径和共享运行资源隔离；凭证兼容及 preflight/提交竞态处置不削弱现有保证。
- S1：单事务选取并 claim；手工 claim 及 reject/reconcile 等重入执行共用预算；不同计划公平、同任务唯一、cmdId 结果可恢复。
- S2：worker 每次明确采用绑定的执行环境；无隔离不启动写执行；失权停止并 reconcile，不借新 token 续旧执行。
- I1：串行合入、冲突停队、冻结候选和集成后验证；分支通过不替代整体交付。
- O1：可查 task/owner/工作区/分支/候选/集成状态及不可执行原因，提供手工恢复流程；若涉及交互，用户人工验收，不默认编写浏览器探针。
- V1：在同一冻结候选完成自动门禁、异常/并发/恢复/旧数据兼容，并获得非实现者审查报告。
- V2：用户按冻结候选明确验收；合入、部署及服务重启各自授权，不由 worker 自行 verify 人审门。

## 4. 必须覆盖的验收矩阵

### 计划与任务

- 同计划与跨计划的独立任务可并行；同任务竞争至多一个有效 owner。
- 无关计划编排变化不使活动任务 rev/契约失效；执行中改依赖/验收被拒且无部分写入。
- revise/adopt/release/转移遵守同一归属规则；任何入口都不能产生双归属或跨计划依赖环。
- 移出当前版本但仍有执行/intent 的任务不会被归档扫描漏掉；取消/重开前置任务的 readiness 政策明确。

### 工作区与 Git

- 不同 worker 的 add/commit 不混入另一任务，HEAD/index/文件互不改变。
- 多工作区落到同 projectId；错误仓库/路径别名/错 session/epoch/token/重复绑定被拒。
- 创建后响应丢失、登记失败、脏 worktree、分支占用、回收失败都保留可核对成果。
- 资源冲突、共享 cache/数据库/端口冲突能被隔离或明确拒绝；worktree 不被误报为安全沙箱。

### 调度、凭证与恢复

- 项目/计划/会话/资源配额在同事务检查；手工领取与恢复入口不绕过配额。
- cmdId 重试不多领；各计划不长期饥饿；空候选有原因；不把普通冲突做成无限重试。
- 实际 cwd、文件 hash、定义版本、候选 commit、intent/attempt/token 与 execution 凭证一致。
- preflight 后提交 stale、失权的在途命令、重启与未知副作用均能 reconcile；不复活旧权或假定执行未发生。
- 旧日志、证据/凭证版本、单工作区项目、读模型与事件消费兼容；失败写入不留下部分 state/lease/绑定。

### 集成与交付

- 两个任务分别通过但组合失败时，集成/最终交付保持未完成。
- 冲突合入、排队期间目标分支前进、候选变化均触发重新验证；审查的 hash 与实际候选一致。
- 人审任务不能由 worker 自行 verify；没有用户合入/部署授权就不执行对应动作。

## 5. 晋级与回退

每项提交须有实现/测试/验收逐条映射。R3 候选冻结后在干净工作树重新跑适用门禁；新增修复或冲突解决后重新冻结并验证，审查者独立于实现者。

回退分别覆盖代码/资产、事件和数据兼容、执行绑定及残留工作区；优先关闭新增并发入口并保留成果/reconcile，不自动删除分支或回滚真实数据。所有破坏性恢复必须有独立授权和可核对目标。

用户验收功能、授权合入、授权部署是三件事。运行 DSH 的重启由用户手动执行，本计划不自动操作主服务或另开替代服务。

## 6. 与其他计划的边界

- 与既有计划多实例/任务流转共享状态与归属契约：统一入口，不复制第二套状态机。
- 与查询模块共享读模型字段：新增字段集中对齐，不改查询表达式语义；热点改动在集成队列协调。
- 与计划级验收、无人值守推进相关但不替代它们：本期不扩展 verify 授权、不自动启动长期驱动器、不自动判定整计划完成。
- 本次不修改其他计划/任务，不建立对整套未完成计划的粗粒度依赖；实施前按真实必要契约决定最小依赖。
