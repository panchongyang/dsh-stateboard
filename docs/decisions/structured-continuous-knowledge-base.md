## 未来方向

**Project Board 的未来定位是结构化连续知识库（Structured Continuous Knowledge Base）。**

这一定位描述项目的演进方向，不表示相关能力已经实现。三个词分别表达：

- **结构化**：知识以有类型、有关系、有来源、有状态的项目事实沉淀，可以追溯依据和历史演变。
- **连续**：知识跨越会话、Agent、任务和时间持续积累，不因执行者更换而丢失。
- **知识库**：核心价值包括让执行者在需要时恢复和使用知识，支持正确继承项目意图并行动。

核心闭环是：

```text
知识形成
决策、任务、审查、证据、执行结果
    ↓
结构化沉淀
关联、来源、版本、状态、历史演变
    ↓
知识检索与上下文恢复
针对当前任务恢复必要的历史知识与约束
    ↓
Agent 正确继承项目意图并行动
    ↓
新行动产生新知识，进入下一轮积累
```

**任务是知识的产生、组织和检索入口之一。**未来的项目知识可以独立于具体任务存在，例如项目决策、架构约束、经验教训和长期目标；它们的具体表达方式留到方案阶段确定。

## 下阶段唯一目标

**让缺乏历史上下文的新会话 Agent，能够围绕当前任务，以尽可能低的时间、Token 和维护成本，恢复足以正确执行任务的历史决策、设计边界、有效约束及其来源证据，正确继承项目意图并行动。**

下一阶段的能力建设围绕这一目标展开。检索算法、存储组件、关系表达、上下文交付和验证方法都是实现手段，不能各自变成脱离该目标的建设目标。

目标的成效体现在：

- 能发现影响当前任务的关键历史信息，包括未直接挂在当前任务上的跨模块约束。
- 能辨别历史讨论、正式决策、适用约束、被替代方案以及尚不明确的部分。
- 能回到原始来源和证据核对，不把模型推断或摘要直接当作权威项目事实。
- 能减少因历史缺失、过时信息或范围误判而产生的错误实现，同时控制阅读、检索和维护成本。

具体指标、样本集和验收阈值在方案阶段讨论；本记录不以返回文本数量、知识条目数量或采用某种检索技术作为达成标准。

## 已确认的设计原则与职责边界

**知识的保存与知识的交付必须分离：保存追求完整、可追溯；交付追求相关、准确、低成本。**

这要求面向任务选择必要上下文，并保留展开与追溯的能力。本阶段复用现有权威记录，只增加可重建的派生检索索引，不由这一原则直接推导新的知识实体。

| 参与方 | 职责 |
|---|---|
| Project Board | 管理项目事实、历史和证据，可以提供检索与来源读取能力 |
| AgentWorkflow | 管理执行流程、检索时机和流程门禁 |
| Agent | 理解材料、判断适用性、处理冲突与不确定性，并对执行决策负责 |

检索相关性、事实权威性和约束有效性分别表达。任务板不代替 Agent 作语义裁决；检索无命中不等于确认不存在约束；生成的摘要不能自动晋升为项目事实。

演进继续遵守[产品方针](<../governance/PRODUCT-PRINCIPLES.md>)：降低使用者心智负担，除 DSH 外不增加使用者必须安装配置的外部依赖，缺能力时可用且如实降级，并把变更安全性和长期可维护性作为一等质量属性。检索能力不得侵入高频任务操作路径或降低现有安全、审计和数据边界。

## 当前阶段与优先级

当前最高优先方向是打通任务板已有数据，建立独立的历史知识读取与检索能力。采用先检索碎片、再由 Agent 沿引用读取原文与有界上下文的两层方式。

传统历史读计划暂停开发，本方向可以取代它；未覆盖的传统能力也继续暂停，不作为前置条件或并行工作。已确认的范围与实现边界见[最小实施方案](<../modules/knowledge/design.md>)。

任务板可能间歇使用，只对实际积累并保留的材料建立重建承诺，不承诺补齐全部工作历史。本阶段复用已有留存材料，不另存外置正文快照；未留存或已丢失的外置正文明确报告不可重建。手动重置基线仅保留为后续议题。

## 方案依据

[历史知识检索与约束恢复技术调研](<../modules/knowledge/design.md>)保存了调查基线上的能力、成熟组件比较、主要难点与候选架构。当前实现采用已确认的最小方向：独立 FTS5 关键词索引、缺能力时有界扫描降级、两层 MCP 搜索与原文读取。

本阶段语料限于任务板已有记录以及通过登记文档、任务证据纳入的外置内容；不扫描整个工作区，不引入 Embedding、向量数据库、GraphRAG、自动记忆生成或独立约束实体。Agent 可自由提出新概念继续搜索，不设累计联想轮数或跳转方向门禁；任务板只控制单次资源与自动附带的已有关系范围。

现行功能以[实现契约](<../CONTRACT.md>)与代码为准；用法见[历史知识读取](<../operations/runbooks/projectboard-usage.md>)，验证范围见[本阶段验证记录](<history-knowledge-validation-2026-11-14.md>)。搜索与来源回读链路的完成，不等于已经证明 Agent 能恢复全部有效约束或减少错误实现。
